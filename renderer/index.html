Changelog
Release history
v1.1.0Latesttriggerbot + defaults update
Triggerbot false hits fixed - stricter red/blue filtering so it no longer fires on random world blocks
Triggerbot missed hits fixed - center crosshair fallback sampling improved for more reliable red/blue detection
Auto Crystal default - delay now defaults to 25ms in UI and runtime fallback paths
Stream-proof mode toggle - default is screenshots allowed; enable this setting to block screenshots/screenshares
Release sync - website and in-app version labels now align with v1.1.0
v1.0.13Single-license update
Double Anchor spacing added a post-detonation buffer so the second anchor doesnt get replaced by glowstone
Inventory D-Hand no longer re-presses inventory on open
Anchor Pearl ends on your totem slot after the pearl
Fast XP hold-to-run instead of toggle
Click binds global left/right click binds for all macros and triggerbot
Defaults SA 27ms, DA 48ms
Sword cleanup removed Shield Stun mode and Stun Web
Triggerbot removed hit key setting
v1.0.7Anchor reliability fix
Anchor macros under rapid mouse movement slot-switch key hold raised from 1ms to 10ms so GLFW always polls the KEYDOWN event before the right-click fires; fixes double-glowstone and wrong-order placements during active camera movement
v1.0.6Triggerbot upgrade
Smart Crit mode waits up to 60ms for the blue crit window before firing; falls back to a normal hit if no crit is available; ~1.5 damage on every critical
S-Tap mode after every hit, briefly taps S to cancel forward momentum so the opponent cannot immediately counter-hit you
Crit detection blue crosshair is now detected alongside red; both Normal and S-Tap modes fire instantly on blue for crits
v1.0.5Fixes & improvements
Anchor macros (SA / DA / AP) single window focus at sequence start; no per-keypress refocus; 1ms holds; fixes wrong-order placements and glowstone-first bugs; ~40% faster
Focus lock class-based window detection (GLFW30 / SunAwtFrame) now catches every Java Minecraft client regardless of title, including fullscreen and modded launchers
Chat Pause moved to all tiers; Basic users can now use the chat pause key
Auto-update app now downloads and installs new versions automatically on next launch
v1.4.0Cart & UHC sections
Cart section new macro category for TNT minecart PVP
Insta Cart (IC) fires a weak bow shot then places rail + cart; the slow arrow detonates the cart on landing
Crossbow (XB) places rail + cart, lights with flint & steel, fires pre-loaded crossbow through fire to detonate
UHC section new macro category for Ultra Hardcore survival
Drain (DR) instantly switch to bucket and scoop fluid
Lava Web (LW) place lava, pick it up, drop cobweb in one sequence
Lava (LA) instantly switch to lava bucket and place
Single Anchor timing reworked to use consistent delay between every individual action (slot switch and click both wait the configured ms), making SA reliable and competitive
v1.3.0Bug fixes
Triggerbot with focus lock off triggerbot now remains active when focus lock is disabled
Windows 10 support macros now work correctly on Windows 10; app requests admin elevation so SendInput reaches elevated Minecraft instances
Fullscreen focus lock focus lock re-detects Minecraft after fullscreen transitions replace the window handle
v1.2.0Mace section
Mace section new macro category for mace & elytra PVP
Elytra Swap (ES) equip elytra and instantly swap back to your weapon
Pearl Catch (PC) throw pearl then follow up with wind charge on a configurable timer
Stun Slam (SS) axe to disable enemy shield, instantly swap to mace and hit
Breach Swap (BS) instant mace hit then swap back to sword in one motion
Updated default delays SA27ms, DA48ms, AP25ms, KP30ms
v1.1.0Bug fixes & improvements
Minecraft detection detects focus correctly when MC is already running on launch; Add-Type fallback prevents silent failures
Anchor macros charge with exactly 1 glowstone before detonating; slot-switch delay enforced so the server always registers the slot change
Offhand Totem totem hotbar slot now switches first, swap-hands key fires second (correct order)
Panic & Chat keys use low-level keyboard hook so the keypress passes through to Minecraft naturally
Mouse clicks switched to keysender hardware flags so Minecraft / GLFW correctly processes right-clicks

Removed Hit Crystal and Sprint Reset macros
